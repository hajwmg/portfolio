## 구현된 주요 기능

### JavaScript (12개 기능)
1. **읽기 진행 바** — 상단 2px 바, 스크롤에 따라 진행률 표시
2. **Navbar 스크롤 효과** — 스크롤 시 반투명 blur 배경 적용
3. **활성 링크 하이라이트** — 현재 뷰포트 섹션 네비 링크 강조
4. **모바일 햄버거 토글** — 열릴 때 X 형태 변환 애니메이션
5. **스무스 스크롤** — 앵커 링크 클릭 시 60px 오프셋 부드러운 이동
6. **fade-up 공통 애니메이션** — IntersectionObserver 기반, stagger 효과
7. **타임라인 등장 애니메이션** — 각 tl-block 순차 표시
8. **스킬바 애니메이션** — 섹션 진입 시 순차적으로 채워지는 바
9. **프로젝트 필터** — 카테고리별 카드 show/hide + 전환 애니메이션
10. **그리드 재배치** — 필터 결과 수에 따라 grid-template-columns 동적 조정
11. **푸터 연도 자동 갱신** — `new Date().getFullYear()` 자동 반영
12. **통합 스크롤 핸들러** — passive 리스너로 성능 최적화

### CSS 특징
- **CSS 변수 기반 테마** — `--accent` 크림골드 포인트 1색
- **Editorial 레이아웃** — 2컬럼 그리드, 세로 타임라인, 수치 강조
- **1px 그리드 구분선** — `background: var(--border)` 갭 트릭으로 깔끔한 분할
- **반응형** — 900px / 640px 브레이크포인트
